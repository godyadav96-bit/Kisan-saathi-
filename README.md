# 🌾 KISAN SAATHI (किसान साथी) – Mandi, Mitti aur Mausam
> **Complete Extensible AI-Powered Agriculture Assistant for Indian Farmers**
> *भारत के किसानों के लिए समर्पित डिजिटल कृषि सहायक — मौसम, मंडी भाव, मिट्टी परीक्षण (SoilSense), फसल सलाह एवं खेती कैलकुलेटर*

---

## 📖 1. Project Overview (परियोजना परिचय)
**Kisan Saathi (किसान साथी)** एक आधुनिक, सरल और विश्वसनीय कृषि वेब एप्लिकेशन और PWA (Progressive Web App) है। इसे विशेष रूप से राजस्थान और पूरे भारत के छोटे और मध्यम किसान भाइयों के लिए डिज़ाइन किया गया है ताकि वे अपनी भाषा (हिंदी / English) में दैनिक कृषि निर्णय सरलता से ले सकें।

### मुख्य सुविधाएं (Core Features):
1. **आज का मौसम व मौसम सलाह (Weather & Mausam Salah):**
   - ओपन-मेटियो (Open-Meteo) लाइव उपग्रह डेटा द्वारा प्रति घंटे, 3 दिन और 7 दिनों का मौसम पूर्वानुमान।
   - तापमान, न्यूनतम/अधिकतम, वर्षा की संभावना (%), हवा की गति व दिशा, आर्द्रता और अलर्ट्स।
   - **Kisan Saathi Mausam Salah:** Gemini AI द्वारा किसान की चुनी हुई फसल, विकास अवस्था व मौसम के आधार पर बुवाई, सिंचाई और कटाई की वैज्ञानिक सलाह।
2. **मंडी भाव (Mandi Bhav):**
   - राजस्थान की प्रमुख अनाज व सब्जी मंडियों (जयपुर मुहाना, सूरजपोल, चौमूं, सीकर, कोटपूतली-बहरोड़, अलवर) के मॉडल, न्यूनतम व अधिकतम भाव।
   - AGMARKNET एवं e-NAM प्रारूप में आवक (Arrival Quantity) व मूल्य रुझान (+/-)।
   - **आज बेचें या रुकें?:** बाजार में आवक और मूल्य दिशा के आधार पर वैज्ञानिक निर्णय सहायता।
3. **मेरी मिट्टी (SoilSense AI):**
   - **वैज्ञानिक सिद्धांत:** मिट्टी की साधारण फोटो से NPK या pH नहीं नापा जा सकता। लैब रिपोर्ट की फोटो/PDF अपलोड करें या मान दर्ज करें।
   - pH मान, नाइट्रोजन (N), फास्फोरस (P), पोटाश (K), और जैविक कार्बन (OC) का विश्लेषण।
   - **खेत में नमी की स्थिति:** किसान द्वारा प्रत्यक्ष अवलोकन (Observation)।
   - मृदा स्वास्थ्य स्कोर, उपयुक्त फसलें और कृषि वैज्ञानिक (KVK) से पूछने योग्य सवाल।
4. **कौन-सी फसल उगाएँ? (Crop Library & Advisor):**
   - 10 प्रमुख फसलें (गेहूं, सरसों, बाजरा, चना, मक्का, प्याज, आलू, टमाटर, धान, जौ) के 10 विस्तृत कृषि मापदंड (सिंचाई अवस्थाएं, कीट नियंत्रण, आदि)।
   - मौसम, मिट्टी और पानी की उपलब्धता के आधार पर वैज्ञानिक फसल अनुशंसा।
5. **खेती कैलकुलेटर (Kheti Calculator):**
   - बीज, खाद, मजदूरी, सिंचाई, डीजल, ढुलाई खर्च बनाम उपज और मंडी भाव से कुल लागत, आय और शुद्ध मुनाफे की सटीक गणना व इतिहास सहेजना।
6. **किसान साथी AI (Gemini Assistant):**
   - बोलकर (वॉइस इनपुट) या लिखकर हिंदी/अंग्रेजी में 24×7 कृषि परामर्श।
   - कभी भी मनगढ़ंत भाव या गैर-प्रमाणित रसायनों की सलाह नहीं देता।
7. **खेती की पूरी जानकारी (Verified Knowledge Library):**
   - ICAR, KVK और कृषि विश्वविद्यालयों द्वारा प्रमाणित लेख (सिंचाई, कीट रोकथाम, PM-KISAN, PMFBY फसल बीमा)।
8. **संस्थापक एवं मालिक नियंत्रण (Owner Admin Dashboard):**
   - ऐप में बिना कोड बदले नई फसलें जोड़ना, मंडी भाव अपडेट करना, नए लेख लिखना, AI सेटिंग्स व मॉड्यूल चालू/बंद करना।
9. **ऑफ़लाइन डेटा कैशे एवं PWA (Offline & PWA):**
   - इंटरनेट न होने पर भी पहले से लोड की गई फसल गाइड, मौसम व मंडी भाव स्पष्ट ऑफ़लाइन लेबल के साथ प्रदर्शित होते हैं।
   - एंड्रॉयड फोन में सिंगल-क्लिक से होम स्क्रीन पर ऐप की तरह इंस्टॉल करने की सुविधा।
10. **पुश नोटिफिकेशन एवं अलर्ट प्रणाली (Push Notification System):**
   - **वेब एवं फोन पुश नोटिफिकेशन:** हेडर में घंटी (🔔) आइकन से सूचना केंद्र खुलता है, जहाँ मौसम अलर्ट, मंडी भाव उतार-चढ़ाव और नई कृषि सलाह श्रेणियां उपलब्ध हैं।
   - **स्वचालित अलर्ट नियम:** वर्षा संभावना >45% होने पर सिंचाई रोकने का अलर्ट, हवा की गति >25 km/h होने पर छिड़काव स्थगित रखने का अलर्ट, तथा किसान की चुनी हुई फसल (जैसे सरसों या गेहूं) के मंडी भाव में तेजी/मंदी पर तुरंत सूचना।
   - **परीक्षण सुविधा:** एक-क्लिक से "टेस्ट अलर्ट भेजें" बटन द्वारा तत्काल नोटिफिकेशन का परीक्षण।

## 🚀 2. How to Run Locally (अपने कंप्यूटर पर कैसे चलाएं)

### पूर्वापेक्षाएँ (Prerequisites):
- [Node.js](https://nodejs.org/) (संस्करण 18 या 20 LTS अनुशंसित)
- npm या bun

### कदम:
```bash
# 1. रिपॉजिटरी क्लोन करें या डाउनलोड की गई डायरेक्टरी में जाएं
cd kisan-saathi

# 2. आवश्यक डिपेंडेंसी इंस्टॉल करें
npm install

# 3. .env फाइल तैयार करें (Gemini API Key जोड़ें)
cp .env.example .env
# .env में अपनी GEMINI_API_KEY दर्ज करें:
# GEMINI_API_KEY="your_gemini_api_key_here"

# 4. डेवलपमेंट सर्वर शुरू करें
npm run dev

# 5. ब्राउज़र में खोलें:
# http://localhost:3000
```

## 🔑 3. External API Configuration (एपीआई कॉन्फ़िगरेशन)

### A. Gemini AI API Key (गूगल जेमिनी):
1. [Google AI Studio](https://aistudio.google.com/) पर जाएं और गूगल अकाउंट से लॉगिन करें।
2. **Get API key** पर क्लिक करें और मुफ्त API Key जनरेट करें।
3. अपनी `.env` फाइल में `GEMINI_API_KEY="आपकी_की"` के रूप में सुरक्षित रखें।
4. AI Studio में काम करते समय यह **Settings > Secrets** पैनल से स्वतः इंजेक्ट होती है।

### B. Open-Meteo Weather API (मौसम डेटा):
- Kisan Saathi **Open-Meteo API** का उपयोग करता है। यह सेवा भारतीय अक्षांश/देशांतर (Latitude/Longitude) के लिए 100% निःशुल्क है और इसके लिए किसी गुप्त क्रेडिट कार्ड या API Key की आवश्यकता नहीं होती।

### C. Mandi Prices (मंडी भाव):
- वर्तमान में यह AGMARKNET एवं राजस्थान राज्य कृषि विपणन बोर्ड के आधिकारिक डेटा प्रारूप से संचालित है। एडमिन पैनल से आप डेटा स्रोत का नाम व ताज़ा रिकॉर्ड नियंत्रित कर सकते हैं।

## 📱 4. Android Phone Installation (अपने फोन में ऐप इंस्टॉल करें)

> **महत्वपूर्ण तथ्य:** GitHub की ZIP फाइल कोई APK (Android Installer) नहीं होती। Kisan Saathi एक **PWA (Progressive Web App)** है, जिसे किसी भी ब्राउज़र से सीधे फोन में असली ऐप की तरह इंस्टॉल किया जा सकता है।

### फोन में चलाने का सबसे आसान तरीका:
1. इस प्रोजेक्ट को किसी निःशुल्क होस्टिंग सेवा (जैसे [Render](https://render.com), [Railway](https://railway.app), या [Vercel](https://vercel.com)) पर डिप्लॉय करें।
2. डिप्लॉयमेंट के बाद मिलने वाले **HTTPS लिंक** (उदा. `https://my-kisan-saathi.onrender.com`) को अपने Android फोन के **Google Chrome** ब्राउज़र में खोलें।
3. स्क्रीन के सबसे ऊपर पीला बटन दिखेगा: **"ऐप इंस्टॉल करें (Install App)"** — उस पर क्लिक करें।
4. अथवा Chrome के ऊपर दायें कोने में 3 डॉट्स (⋮) पर क्लिक करें और **"Add to Home Screen"** या **"Install App"** चुनें।
5. आपके फोन के होम स्क्रीन पर **किसान साथी का हरा-पीला लोगो** बन जाएगा। अब आप इसे बिना ब्राउज़र बार के फुल-स्क्रीन नेटिव ऐप की तरह चला सकते हैं!

### ऑफ़लाइन क्या चलेगा?
- **ऑफ़लाइन उपलब्ध:** फसल निर्देशिका (10 फसलों की पूरी जानकारी), खेती कैलकुलेटर, सहेजी गई पुरानी मृदा रिपोर्ट, और अंतिम बार लोड किया गया मौसम व मंडी भाव।
- **इंटरनेट आवश्यक:** नया लाइव मौसम, ताज़ा मंडी भाव और Gemini AI से बातचीत।

## 🛡️ 5. Owner / Admin Setup (संस्थापक मालिक नियंत्रण कैसे लें)

आप इस एप्लिकेशन के संस्थापक और मालिक हैं। एडमिन पैनल को सुरक्षित रखा गया है:

1. ऐप के ऊपर हेडर में **"Admin"** बटन पर क्लिक करें (या नीचे प्रोफाइल में जाकर "मालिक डैशबोर्ड" चुनें)।
2. सुरक्षा स्क्रीन पर अपना गुप्त पिन दर्ज करें।
   - **डिफ़ॉल्ट संस्थापक पिन (Default Bootstrap PIN):** `123456`
3. डैशबोर्ड खुलने के बाद **"7. सामान्य सेटिंग्स व पिन"** टैब में जाकर अपना निजी नया पिन तुरंत बदल लें।
4. **एडमिन से आप क्या-क्या नियंत्रित कर सकते हैं?**
   - **फसल प्रबंधन:** नई फसलें (जैसे जीरा, सौंफ, इसबगोल) जोड़ना और उनकी जानकारी संपादित करना।
   - **ज्ञान पुस्तकालय:** किसानों के लिए नए लेख प्रकाशित करना।
   - **मंडी प्रबंधन:** नई मंडियां जोड़ना व भाव अपडेट करना।
   - **फीचर टॉगल:** किसान बाजार (Marketplace) और प्रीमियम प्लान को ऑन/ऑफ करना।

## 📂 6. How to Export & Upload to GitHub (प्रोजेक्ट को गिटहब पर डालना)

### A. Google AI Studio से प्रोजेक्ट डाउनलोड करना:
1. AI Studio के ऊपर दायें कोने में मेनू से **"Export / Download Project (ZIP)"** चुनें।
2. फाइल आपके कंप्यूटर पर `kisan-saathi.zip` के रूप में डाउनलोड हो जाएगी।
3. इसे राइट-क्लिक करके **Extract All** (अनज़िप) करें।

### B. GitHub पर अपलोड करना (शुरुआती संस्थापकों के लिए):
1. [GitHub.com](https://github.com/) पर जाएं और निःशुल्क खाता बनाएं।
2. ऊपर दायें कोने में **"+"** आइकन दबाकर **"New repository"** पर क्लिक करें।
3. रिपॉजिटरी का नाम रखें: `kisan-saathi`, इसे **Public** रखें और **Create repository** दबाएं।
4. पेज पर दिए गए **"uploading an existing file"** लिंक पर क्लिक करें।
5. अपने अनज़िप किए गए फोल्डर की सभी फाइलें खींचकर (Drag & Drop) अपलोड करें।
6. नीचे **"Commit changes"** दबाएं। आपका कोड GitHub पर सुरक्षित हो गया!
